Sample Course Schedule

The week-by-week schedule, with links to readings, assignments, and materials for each session. Details will fill in as the semester approaches.

Weekly Structure

  • Fridays are mostly reserved for AI tutorials and skill development, which live in Xiaoyang’s Vibecoding textbook.
  • Each week’s materials are organized around our MWF class meetings, with suggested finish times to help you stay on pace. You’ll get the most out of class if you keep up with the MWF rhythm.
  • Readings are never “due” — but they often have exercises embedded in them. The weekly assignment — linked from each week below — collects those embedded exercises and questions, plus the ones from Friday’s tutorial, and is due Sunday at 11:59 PM.

Instructor note

The Unit 1 + Surface/Observe re-read is a placeholder recommendation (Claude’s): Unit 1 pairs naturally with chat-only basic builds while setup runs in parallel, and its Surface drills feed the Mon/Wed in-class practice. Swap in whatever SOLVE assignment you settle on.

Friday runs as checkpoint + stretch: a quick smoke test everyone performs (agent reads a file, runs a line of code, writes a small file — three checks, two minutes), then triage. Stuck students get hands-on help; finished students do the first-flight build — a tiny, fun, self-contained agent task (e.g., build a one-page personal tool) that exercises the fresh setup and previews Module 4’s workflow — and peer-debugging, which doubles as a diagnostic for who’s actually set up versus who thinks they are. The smoke test and first-flight exercise need writing — they can live on this tutorial’s future page.
